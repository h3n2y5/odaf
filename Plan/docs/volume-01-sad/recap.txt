Fase 1 — Arsitektur Platform
Volume 1 (SAD) dengan struktur berbasis ISO 42010 + arc42 + C4 + RFC.
Semua prinsip, keputusan arsitektur (ADR), dan model kualitas ditetapkan di sini.
Fase 2 — Meta Model
Volume 2 mendefinisikan meta model ODAF (Application, Module, Menu, Resource, Page, Region, Component, Dataset, Workflow, Permission, dll.).
Dari meta model inilah ERD Oracle dan DDL diturunkan.
Fase 3 — Compiler & Runtime
Volume 3 mendefinisikan kontrak antarmuka (Compiler, Runtime, Renderer, DatasetProvider, PermissionProvider, dll.) sebelum satu baris kode PHP ditulis.
Fase 4 — Studio
Volume 4 mendefinisikan ODAF Studio sebagai IDE metadata-driven.
Fase 5 — ERP Reference Implementation
Volume 5 menunjukkan bagaimana seluruh spesifikasi diwujudkan dalam ERP lengkap.
